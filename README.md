# My Website

This is a simple website built using HTML and Tailwind CSS.

## About the Project

This project is a basic web page where I practice front-end development skills.  
It includes simple styling using Tailwind classes to improve the design.

## Features

- Clean and simple layout
- Styled using Tailwind CSS
- Responsive design (works on different screen sizes)
- Easy to edit and expand

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript (if needed later)

## How to Run

1. Download or clone the project
2. Open `index.html` in your browser
3. Done 👍
